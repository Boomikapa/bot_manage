NLP preprocessing with NLTK (tokenization + lemmatization).
Uses Bag of Words (CountVectorizer) to convert text into numeric features.
Trains a Naive Bayes classifier for intent classification.
Generates responses with relevant emoji based on the predicted intent.

-----------------------------------------------------------------------------

In Python, re stands for the Regular Expressions module — it is used to search, match, and manipulate text patterns (like email IDs, phone numbers, dates, etc.) inside strings.
